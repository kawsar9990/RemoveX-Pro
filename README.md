**RemoveX** is a fast, AI-powered web application designed to automatically remove and replace image backgrounds in seconds with precision. Built using Next.js App Router, TypeScript, and modern web technologies.

---

## ⚡ Features

* **Instant AI Background Removal:** Automatically detect and remove image backgrounds with high precision.
* **Custom Backgrounds & Solid Colors:** Replace removed backgrounds with custom backdrops or solid color options.
* **High-Resolution Export:** Download processed images seamlessly in pristine quality.
* **Cloud & Database Integration:** Powered by Supabase and Cloudinary for media storage and user management.
* **Responsive Modern UI:** Built with Tailwind CSS for a sleek experience across all devices.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Database & Auth:** [Supabase](https://supabase.com/)
* **Image Processing & Storage:** [Cloudinary](https://cloudinary.com/) & `@imgly/background-removal`
